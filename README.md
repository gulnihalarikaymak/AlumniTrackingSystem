# Alumni Tracking System
 This is a code bundle for ATS. The original web site is available at;
 
 https://ats.figma.site/
  
## Overview

Alumni Tracking System is a web-based application designed to help universities maintain communication with graduates, track career development, and manage alumni-related information efficiently.

The project aims to create a centralized platform where alumni data can be stored, updated, and analyzed, strengthening the relationship between institutions and their graduates.

---

## Features

- Alumni profile management
- Graduate information tracking
- Career status monitoring
- Search and filtering functionality
- Responsive user interface
- Modern web application architecture

---

## Technologies Used

- TypeScript
- HTML5
- CSS3
- Vite
- Figma Make

---

## Project Goals

The primary objective of this project is to provide universities with a digital platform that enables:

- Efficient alumni management
- Better communication with graduates
- Collection of career-related data
- Long-term alumni engagement
